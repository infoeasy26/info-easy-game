# Info Easy — حزمة التطبيق القابل للتثبيت (PWA)

## محتويات المجلد
- `index.html` — اللعبة كاملة (بما فيها نسخة احتياطية من البنك وصورة المخبر).
- `questions-bank.js` — بنك الأسئلة المستقل (يُعتمد هو إن وُجد).
- `manifest.webmanifest` — بيانات التطبيق (الاسم، الأيقونات، وضع ملء الشاشة).
- `sw.js` — خدمة العمل دون إنترنت.
- `icons/` — أيقونات التطبيق (من شخصية المرشد الآلي).

> ارفعي **كل المجلد بما فيه `icons`** إلى الاستضافة. لا تغيّري أسماء الملفات.

## 1) النشر المجاني على GitHub Pages
1. أنشئي حساباً على github.com، ثم **New repository** باسم مثل `info-easy` واجعليه **Public**.
2. اضغطي **Add file ← Upload files** واسحبي كل محتويات هذا المجلد (ومعها المجلد `icons`)، ثم **Commit changes**.
3. من **Settings ← Pages**: اختاري **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة أو اثنتين يظهر الرابط: `https://اسم-حسابك.github.io/info-easy/`

## 2) التجربة على هاتف Android
1. افتحي الرابط في **Chrome**.
2. اضغطي زر **📲 ثبّت التطبيق** الذي يظهر أسفل الشاشة، أو القائمة ⋮ ثم **تثبيت التطبيق / Add to Home screen**.
3. ستظهر أيقونة «Info Easy» على الشاشة الرئيسية، ويُفتح التطبيق بملء الشاشة ويعمل **دون إنترنت** بعد أول فتح.

## 3) تحديث اللعبة لاحقاً
1. ارفعي الملفات الجديدة فوق القديمة.
2. في `sw.js` غيّري `const VERSION = 'infoeasy-v1'` إلى `infoeasy-v2` ثم v3 وهكذا.
3. يحصل التلاميذ على النسخة الجديدة عند فتح التطبيق مرة أو مرتين مع توفر الإنترنت.

## 4) ملاحظات مهمة
- **التقدم المحفوظ منفصل لكل رابط:** ما حُفظ على حواسيب المخبر (فتح الملف مباشرة) لا ينتقل تلقائياً إلى نسخة الويب. لنقله: من لوحة الأستاذ ← «نسخة احتياطية» على الحاسوب، ثم «استيراد ودمج» في نسخة الويب.
- **الصوت:** ضعي `music.mp3` بجانب `index.html` إن أردتِ موسيقاك، وسيُخزَّن تلقائياً للعمل دون إنترنت.
- **صورة البازل:** الصورة مدمجة؛ ولاستبدالها ضعي `lab.jpg` بجانب `index.html`.
- **كلمة سر الأستاذ:** غيّريها داخل `index.html` (ابحثي عن `TEACHER={code:`) قبل النشر.
- لا يعمل التثبيت إلا عبر رابط **https** (مثل GitHub Pages)، لا بفتح الملف مباشرة من الحاسوب.

## 5) الخطوة التالية: Google Play
بعد التأكد من عمل التطبيق على الهاتف، يُحوَّل الرابط إلى حزمة AAB بأداة **PWABuilder** (pwabuilder.com) ثم يُرفع إلى Play Console. نجهّز ذلك معاً في الخطوة التالية.
